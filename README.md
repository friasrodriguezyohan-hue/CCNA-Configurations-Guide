# Networking Fundamentals
>¿Que es una red?
>
>Una red informática es un conjunto de dispositivos interconectados que se comunican entre sí para intercambiar datos y compartir recursos.

# Routers

>Un router (o enrutador) es un dispositivo que conecta tu red doméstica o de oficina a Internet. Actúa como un cerebro central que recibe la conexión de tu proveedor, crea una red local (Wi-Fi o cable) y distribuye el tráfico de datos entre todos tus dispositivos.
